NetMonitor Pro 2.0
=================

This is a flat-source Android starter project. GitHub Actions recreates the
normal Android folder structure before building.

Build:
1. Push all files to the repository root.
2. Open Actions.
3. Select "Build NetMonitor Pro APK".
4. Run workflow.
5. Open the successful run and download the artifact "NetMonitor-Pro-APK".

The build uses Gradle 8.9 + Android Gradle Plugin 8.7.3 + JDK 17.
